Billionaire Management System

A C-based command-line application that manages a database of billionaires using a **circular doubly linked list**.

The program allows users to:
- Add new billionaire records with personal information and net worth.
- Delete the newest or oldest entries.
- Search for billionaires by name, city/country, or main activity.
- Filter records by birth date, birth time, and net worth.
- Calculate the total wealth of all registered billionaires.
- Generate unique account numbers with check digits.
- Save records to and load records from text files.

The project demonstrates the use of **structures, pointers, dynamic memory allocation, linked lists, string manipulation, and file handling in C.

HOW TO RUN 

gcc code1.c -o code1
